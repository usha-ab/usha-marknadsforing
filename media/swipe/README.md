det bra. Veckobatchen mäts mot det här: "är vår variant minst lika bra som
den bästa referensen i samma vinkel?"

## Vad vi letar efter

- Dans-, yoga-, klätter- och träningskonton som säljer **vad man lär sig**, inte stämningen.
- Lokala Stockholmskonton med bokningslänk i bion – hur de gör vägen in kort.
- Annonser från plattformar som säljer biljetter/kurser (hur de visar priset och tröskeln).

## Vad vi inte tar in

Nattklubbsestetik, influencer-dans utan pedagogik, allt som bygger på kändisar.
