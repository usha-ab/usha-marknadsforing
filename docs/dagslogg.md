# Daglig framstegslogg

Skrivs varje dag (sista handlingen) till Google Drive-mappen **Usha – Daglig logg**:
https://drive.google.com/drive/folders/1IvYVKYSiObXO1SeXGyD_sN8HvPyjzyK7

Ett dokument per dag, `YYYY-MM-DD – Framsteg`, med rubrikerna GJORT I DAG / BESLUT I DAG / NÄSTA STEG / LÄNKAR, och en kalenderpost kl 23:30 med länk. En molnrutin kl 21:30 sammanfattar dagens kodaktivitet om ingen logg skrivits.
